我们优先将爆出的相应用户名，制作成一个users.txt

```
import re

# Read data from a file
with open('usersinfo.txt', 'r', encoding='utf-8') as file:
    data = file.read()

# Extract lines with SidTypeUser
sidtypeuser_lines = [line for line in data.splitlines() if "SidTypeUser" in line]

# Extract full usernames after '\'
usernames = [re.search(r'\\([\w.]+)', line).group(1) for line in sidtypeuser_lines]

# Write usernames to a file
with open('users.txt', 'w', encoding='utf-8') as file:
    for username in usernames:
        file.write(username + '\n')
```
