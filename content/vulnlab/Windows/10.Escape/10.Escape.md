针对目标服务器进行相应的端口扫描

```
sudo nmap -sS -vvv 10.10.123.98
```

![image-20241228203516993](https://s2.loli.net/2024/12/28/uGJ1lBobdA4SX8Y.png)

针对目标服务器开放端口进行相应的服务扫描

```
sudo nmap -p3389 -A 10.10.123.98 -oN Escape.txt
```

![image-20241228204025887](https://s2.loli.net/2024/12/28/cKT9y68ZeIG4pgP.png)

只有一个端口可以用来进行突破，我们先访问下

```
rdesktop 10.10.123.98
```

我们将下载的cmd，修改名称未msedge，就能够正常运行了

```
cd C:\Program Files (x86)\Remote Desktop Plus\
.\rdp.exe
copy c:\_admin\profiles.xml .
```

![image-20241228215607377](https://s2.loli.net/2024/12/28/iYvEJjztOMITa8f.png)

manage profies 然后import相应的配置信息然后点击edit编辑，我们需要打开[BulletsPassView](https://www.nirsoft.net/utils/bulletspassview-x64.zip) 这个工具，但直接双击无法启动，我们可以使用cmd来启动

```
.\BulletsPassView.exe
```

password:Twisting3021

![image-20241228220555750](https://s2.loli.net/2024/12/28/5tleJKnURkcZTsP.png)

我们又了一个密码，我们尝试这个密码能如何访问

![image-20241228220707158](https://s2.loli.net/2024/12/28/uETmwt5MIYNahSo.png)

```
runas /user:ESCAPE\admin cmd
```

![image-20241228220823618](https://s2.loli.net/2024/12/28/bMWfiSYU4EBctJR.png)

我们尝试了几个之后发现这个密码能切换到admin用户，但这个admin用户虽然属于administrator组，但privileges是不全的，属于中等完整权限，应该是需要绕过UAC

```
powershell
Start-Process powershell -Verb runas

```

![image-20241228221027141](https://s2.loli.net/2024/12/28/8rkStquaifRWw7h.png)

我们就有完整权限了，去到相应目录下获取对应的flag
