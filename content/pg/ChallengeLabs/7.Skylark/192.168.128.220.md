针对目标服务器端口进行相应的探测

```
sudo nmap -p- -Pn -vvv --min-rate 5000 192.168.128.220
```

![image-20250115220656781](https://s2.loli.net/2025/01/15/e1u2gpbaJ7Cs4Mf.png)

针对目标服务器的开放端口进行相应的服务探测

```
sudo nmap -p80,135,139,445,5900,5985,47001 -Pn -A 192.168.128.220 -oN 192.168.128.220.txt
```

![image-20250115221706089](https://s2.loli.net/2025/01/15/LpKJ4dMkXnA8qry.png)
