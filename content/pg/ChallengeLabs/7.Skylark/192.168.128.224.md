针对目标服务器端口进行相应的探测

```
sudo nmap -p- -Pn -vvv --min-rate 5000 192.168.128.224
```

![image-20250115222805344](https://s2.loli.net/2025/01/15/rNuY19vFwjL7sAq.png)

针对目标服务器的开放端口进行相应的服务探测

```
sudo nmap -p22,3128,8000 -Pn -A 192.168.128.224 -oN 192.168.128.224.txt
```

![image-20250115222817575](https://s2.loli.net/2025/01/15/CSZcuydUWLrOTPj.png)

22端口没有可以直接利用的内容，我们查看3128和8000端口

```
python spose.py --proxy http://192.168.128.224:3128 --target 192.168.128.224
```
