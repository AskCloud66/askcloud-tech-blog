针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.107.172
```

```
sudo nmap -p53,88,135,139,389,445,464,593,636,3268,3269,3389,5985,9389,49666,49668,49673,49674,49679,49703 -A -sC
 192.168.107.172 -on Vault.txt

```

