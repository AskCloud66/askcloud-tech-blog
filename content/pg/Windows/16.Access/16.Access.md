但返回的都是主界面，考虑到上传的特征，我们怀疑是服务器后端针对部分后缀名进行了过滤，如果我们上传一些特殊的后缀，实际是能够显示代码的，只是没有解析

![image-20241214220843907](https://s2.loli.net/2024/12/14/1uw5FKqVvMh6D34.png)

我们考虑在目标目录上传一个.htaccess配置文件，能够让服务器使用php解析一些特殊的文件后缀，例如我们修改上传后缀为xyz

```
cp win_shell.php win_shell.xyz
echo "AddType application/x-httpd-php .xyz" > .htaccess
```
