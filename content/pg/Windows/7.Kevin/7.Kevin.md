针对服务器进行端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.174.45 --open
```

![image-20241109201340036](https://s2.loli.net/2024/11/09/J4CubEcPO2jt3wB.png)

针对开放端口进行进一步探测

```
 sudo nmap -p80,135,139,445,3389,3573,49152,49153,49154,49155,49158,49160 -A -sC 192.168.174.45 -oX kevin.xml
```

![image-20241109201359731](https://s2.loli.net/2024/11/09/ykoVuCX7IApZHq3.png)

优先从80端口开始探测，页面上展示这是一个hp power manager系统，通过Google搜索关键字“hp power manager default credentials”
