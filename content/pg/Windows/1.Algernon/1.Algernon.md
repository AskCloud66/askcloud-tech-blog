针对目标服务器进行端口扫描

```
sudo nmap -p- --min-rate 10000 192.168.115.65
```

针对开放端口上的服务进行进一步的探测工作

```
sudo nmap -p21,80,135,139,445,5040,9998,17001,49665,49666,49667 -A 192.168.115.65 -oX Algernon.xml
```

![image-20241105234130751](https://s2.loli.net/2024/11/05/oxblwPh64F9uXWv.png)

首先针对21端口的匿名登录进行登录尝试

```
ftp 192.168.115.65 21
prompt OFF
cd Logs
mget *.log
```
