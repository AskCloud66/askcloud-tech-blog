针对服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.110.16
```

![image-20241121221531077](https://s2.loli.net/2024/11/21/VPGKT8ZeshtQUjJ.png)

针对开放的端口进行相应的服务扫描

```
sudo nmap -p22,80 -A 192.168.110.16 -oG Extplorer.txt
```

![image-20241121221541210](https://s2.loli.net/2024/11/21/xIywpzLZsNjX3KC.png)
