针对服务器端口进行探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.106.24
```

针对服务器开放端口进行探测

```
sudo nmap -p22,8000 -A 192.168.106.24 -oG Levram.txt
```

![image-20241120224801981](https://s2.loli.net/2024/11/20/dGBt4J9Zeb8sQzh.png)

22端口没有可以直接利用的相关漏洞，我们重点关注8000端口，我们优先针对8000端口进行路径扫描

```
dirsearch -u http://192.168.106.24:8000/
```
