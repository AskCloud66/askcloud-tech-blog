针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.168.210
```

针对相应的开放端口进行相应的服务扫描

```
sudo nmap -p22,8000 -A 192.168.168.210 -oG PC.txt
```

![image-20241124220113348](https://s2.loli.net/2024/11/24/wDGxlcmPOhIuVeU.png)

22端口没有直接能够获取的，针对8000端口进行相应的漏洞检查

8000端口根据nmap的扫描结果，相应运行的是ttyd 1.7.3版本，同时我们通过访问，这实际是一个terminal的页面

![image-20241124220421106](https://s2.loli.net/2024/11/24/oqp9EYCm81Ib4HK.png)

我们发现本地还有一个65432端口服务，我们尝试使用端口转发工具进行扫描

```
被攻击端
./chisel_1.10.1_linux_amd64 client 192.168.45.227:4444 R:65432:127.0.0.1:65432


攻击端
./chisel_1.10.1_linux_amd64 server -p 4444 --reverse

执行扫描
sudo nmap -sV 127.0.0.1 -p 65432 -A 
```
