针对目标服务器进行相应的端口扫描

```
 sudo nmap -p- -vvv --min-rate 10000 192.168.227.148
```

![image-20241208182718176](https://s2.loli.net/2024/12/08/hPxzlj5NYUs3u7O.png)

针对目标服务器开放端口进行进一步的服务探测

```
sudo nmap -p20,21,22,53,80,123,137,138,139,666,3306,12380 -A 192.168.227.148 -oG Stapler.txt
```

![image-20241208182739668](https://s2.loli.net/2024/12/08/6ZiDxucpKhAF7RX.png)

我们针对开放的端口逐个进行检查，我们优先从21端口开始进行探测检测，21端口从扫描的结果看是允许匿名登录的，我们优先进行登录，查看能够访问哪些目标文件

```
ftp 192.168.227.148 21
```

![image-20241208183105399](https://s2.loli.net/2024/12/08/51ysgDKvzqkWLFB.png)

banner中显示了一个名称：harry

ftp内显示一个文件note，我们针对note文件进行下载，并针对note文件进行查看

![image-20241208183251821](https://s2.loli.net/2024/12/08/rgDNSOpbqxdZLAU.png)

我们又发现了两个用户名称elly，john，同时按照说明提示，elly的ftp目录中应当有信息，我们尝试用这三个用户进行匿名或者弱密码登录，但登录的尝试均失败，我们把用户名记录完成后，先看别的端口和服务

22端口没有什么额外可以利用的点

139的samba服务，我们优先进行下扫描

```
enum4linux-ng 192.168.227.148 -A -C
```

![image-20241208184117449](https://s2.loli.net/2024/12/08/9LozNqMxE4wcBTl.png)

![image-20241208184139640](https://s2.loli.net/2024/12/08/gAFIHuyZ5dtnamf.png)

```
enum4linux 192.168.227.148 -a
```

![image-20241208200850897](https://s2.loli.net/2024/12/08/Utqz4Snsl8yJZkN.png)

```
smbclient -L //192.168.227.148 
```

![image-20241208184234392](https://s2.loli.net/2024/12/08/9fthKYjZCVEoLpJ.png)

可以进行匿名访问，可以看到注释和文件名，我们又获得了kathy和fred两个用户名，我们登录几个目录查看是否存在可利用的有价值文件

```
smbclient -N //192.168.227.148/kathy
smbclient -N //192.168.227.148/tmp
```
