针对服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.106.23
```

针对开放端口进行相应的

```
sudo nmap -p22,80 -A 192.168.106.23 -oG Codo.txt
```

![image-20241120213408657](https://s2.loli.net/2024/11/20/dY3O6QV8xcGn5vh.png)
