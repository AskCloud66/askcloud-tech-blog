针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -vvv --min-rate 10000 192.168.106.25
```

针对开放的端口进行相应的服务扫描

```
sudo nmap -p22,80,8082,9999 -A 192.168.106.25 -oG Hub.txt
```

![image-20241122201808197](https://s2.loli.net/2024/11/22/7UsAnlbJgNvCfqW.png)

22端口没有可以直接利用的漏洞和内容，我们直接从80，8082和9999三个http服务开始查看

80端口访问为403，我们尝试进行下403bypass和路径扫描

```
/home/zkpc/Tools/bypass-403/bypass-403.sh http://192.168.106.25/
```

![image-20241122210657235](https://s2.loli.net/2024/11/22/D97NBqIsgK4ftWG.png)
