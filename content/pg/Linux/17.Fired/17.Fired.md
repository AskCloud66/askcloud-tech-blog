针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.213.96
```

![image-20241125215938297](https://s2.loli.net/2024/11/25/rmPAiEdXjJ8bfLG.png)

针对目标服务器的开放端口进行服务探测

```
sudo nmap -p22,9090,9091 -A  192.168.213.96 -oG Fired.txt
```

![image-20241125220500651](https://s2.loli.net/2024/11/25/MvlkUYrLeajJCA8.png)

22端口没有可以直接利用的内容，我们直接针对9090及9091端口进行检测，9091属于https版本，实际是相同的服务内容，

![image-20241125220658881](https://s2.loli.net/2024/11/25/Z1TSCxjYfQFl2wd.png)


我们优先使用Google搜索进行相应的版本检测，是否存在可以利用的漏洞内容及默认的认证信息

搜索关键字：openfire 4.7.3 exploit

搜索关键字：openfire default credentials
