从该部分代码可以看到会从ldap表中取出加密字段，然后进行解密，有一个密钥c4scadek3y654321

在dll文件中还发现了一个密钥“1tdyjCbY1Ix49842”

![image-20241025174200596](https://files.seeusercontent.com/2026/04/07/Bj3l/image-20241025174200596.png)

可以看到是AES算法

使用python进行解密

```
import pyaes
from base64 import b64decode
key = b"c4scadek3y654321"
iv = b"1tdyjCbY1Ix49842"
aes = pyaes.AESModeOfOperationCBC(key, iv = iv)
decrypted = aes.decrypt(b64decode('BQO5l5Kj9MdErXx6Q6AGOw=='))
print(decrypted.decode())
```

```
python3 decodeAES.py
```

属于AD RECYCLE bin组，查看这个组的特殊之处，是一个著名的 Windows 组是 Server 2008 中添加的一项功能，允许管理员恢复已删除的项目，就像回收站对文件的作用一样。链接的文章提供了一个 PowerShell 命令来查询域中所有已删除的对象：(https://blog.netwrix.com/2021/11/30/active-directory-object-recovery-recycle-bin/)

```
Get-ADObject -filter 'isDeleted -eq $true -and name -ne "Deleted Objects"' -includeDeletedObjects
```

![image-20241025182527040](https://s2.loli.net/2024/10/25/BzSVvxXoFZLRiJn.png)

看到最后有一个临时admin，针对该部分内容进行单独恢复

```
Get-ADObject -filter { SAMAccountName -eq "TempAdmin" } -includeDeletedObjects -property * > TempAdmin.txt
```
