针对目标服务器进行相应的端口扫描

```
sudo nmap -p- -Pn -vvv --min-rate 1000 10.10.11.232
```

![image-20250115163443550](https://s2.loli.net/2025/01/15/8g4ek6ytDHM1B52.png)



针对目标开放的端口进行相应的服务扫描

```
sudo nmap -p22,80,111 -A -Pn 10.10.11.232 -oN Clicker.txt
```

![image-20250115163658548](https://files.seeusercontent.com/2026/04/07/a1fJ/image-20250115163658548.png)

22端口没有什么可以利用的内容，我们优先查看111端口

https://book.hacktricks.wiki/en/network-services-pentesting/pentesting-rpcbind.html?highlight=port%20111#111tcpudp---pentesting-portmapper

我们在这个链接中找到了一些提示

根据nmap的扫描结果，存在nfs服务，我们可能能列出一些文件内容

```
nmap -sSUC -p111 10.10.11.232
```

![image-20250115165919941](https://s2.loli.net/2025/01/15/2wxjigt6mRWCKb9.png)

```
showmount -e 10.10.11.232
```

![image-20250115170233296](https://s2.loli.net/2025/01/15/HDvArgUTx8u7E1J.png)

```
sudo mount -t nfs 10.10.11.232:/mnt/backups /mnt/backup -o nolock
cd /mnt/backup
```

![image-20250115170403263](https://s2.loli.net/2025/01/15/EwysvX1z8OBpIkV.png)

我们复制下来进行相应的分析工作

